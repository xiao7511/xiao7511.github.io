# NOBI iOS branding masters

The icon derives from `public/favicon.svg`: the same pink-to-blue brand gradient and white NOBI mark. The committed 1024×1024 app icon is opaque and square so iOS can apply its own mask. The splash uses the same mark on the app's `#10131b` background.

`generate_assets.py` documents the raster generation and is not part of the app build. Run it with Python and Pillow only when the master artwork changes.
